# Fraud Detection Project

This project uses the IEEE Fraud Detection dataset to build machine learning models for detecting fraudulent transactions.

## Project Structure

```
FraudDetection/
├── data/               # Dataset files (CSV files)
├── notebooks/          # Jupyter notebooks for analysis and modeling
│   ├── analysis/      # Exploratory data analysis
│   └── modeling/      # Model development
├── src/               # Source code
│   ├── templates/     # Code templates
│   └── tests/         # Unit tests
├── docs/              # Documentation
└── attributes.txt     # Dataset description
```

## Dataset Description

The dataset contains transaction data from a real payment provider fraud detection system.

See `attributes.txt` for detailed information about the dataset features.

## Getting Started

1. Download the dataset files from Kaggle and place them in the `data/` folder:
   - train_transaction.csv
   - train_identity.csv
   - test_transaction.csv
   - test_identity.csv
   - sample_submission.csv

2. Install required dependencies

3. Start with the notebooks in the `notebooks/` folder

Data files are not included in the repository due to their large size. Please download them separately from the competition page.
